プライバシーポリシー

駐車練習（iPhone / iPad アプリ・ウェブ版）　最終更新日：2026年11月15日（iCloud への保存を追記）

「駐車練習」（以下「本アプリ」）は、利用者の情報を次のように取り扱います。

1. 本アプリが集める情報

本アプリは、名前・メールアドレス・位置情報などの個人情報を集めません。アカウント登録もありません。

ステージの進み具合、過去最高得点、バッジ、設定は、お使いの端末の中に保存されます。iOS アプリ版では、アプリを入れ直したときや機種変更のときに引き継げるように、同じ内容をお使いの Apple ID の iCloud にも保存します。iCloud に保存した内容は Apple が管理し、本アプリの運営者が見たり受け取ったりすることはありません。

2. 広告（iOS アプリ版）

iOS アプリ版では、Google LLC の広告サービス「Google AdMob」を使って広告を表示しています。AdMob は、広告の表示や効果の測定のために、端末の識別子（広告 ID）、IP アドレス、おおよその地域、アプリの利用状況などの情報を集めることがあります。

広告 ID は、アプリが最初に表示する「トラッキングの許可」の確認で許可した場合にだけ使われます。許可しなくても、アプリはすべての機能を使えます。設定は、端末の「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

Google による情報の取り扱いは、Google の広告に関するポリシーとGoogle プライバシーポリシーをご覧ください。

ウェブ版には広告はありません。

3. アプリ内課金

「広告を削除＋ハードステージ解放」の購入は、Apple の App Store を通して行われます。お支払いの情報は Apple が扱い、本アプリの運営者が受け取ることはありません。購入済みかどうかの情報だけを、端末の中に保存します。

4. 第三者への提供

上記の広告サービスを除き、利用者の情報を第三者に提供することはありません。

5. お子さまの利用

本アプリは、13歳未満のお子さまを対象にしたものではありません。

6. このポリシーの変更

内容を変更するときは、このページを更新します。

7. お問い合わせ

GitHub の Issues からお問い合わせください。
